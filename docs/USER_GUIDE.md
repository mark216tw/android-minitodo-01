# Mini 待辦事項使用指南

本文件說明 Mini 待辦事項的安裝方式、主要操作與常見問題。介面文字以繁體中文為主，並依 Android 系統語言調整日期與時間格式。

## 1. 系統需求

- Android 8.0（API 26）以上
- 建議 Android 12 以上以使用動態主題色彩
- 不需要網路連線
- 不需要註冊帳號

## 2. 安裝 App

### 使用 GitHub Release 的測試版 APK

1. 前往 GitHub Release 頁面，下載 `app-prerelease.apk`。
2. 在 Android 裝置上開啟下載的 APK。
3. 若系統提示「不允許安裝未知來源的應用程式」，請依指示允許該瀏覽器或檔案管理器安裝 APK。
4. 安裝完成後開啟「Mini 待辦事項」。

> `app-prerelease.apk` 為預覽測試版本，使用 Debug 金鑰簽署，僅供測試，不建議長期保存重要資料。

### 使用 Android Studio 安裝

1. 以 Android Studio 開啟專案。
2. 選擇裝置或模擬器。
3. 執行 `app` 組態，或使用 `./gradlew installDebug`。

## 3. 第一次使用

首次開啟時，若尚無資料，畫面會顯示「還沒有待辦」與「新增待辦」按鈕。

1. 點選右下角「＋」或畫面上的「新增待辦」。
2. 輸入待辦標題。
3. 視需要選擇顏色與新增清單項目。
4. 點選右上角「儲存」。

未輸入標題時無法儲存；若已修改內容卻直接返回，App 會詢問是否放棄變更。

## 4. 新增與編輯待辦

### 待辦欄位

| 欄位 | 說明 |
| --- | --- |
| 標題 | 必填，顯示於清單卡片 |
| 顏色 | 16 種選項，含「無顏色」；顏色顯示於卡片左側色條與桌面小工具 |
| 標記待辦完成 | 沒有清單項目時，直接控制待辦完成狀態 |
| 待辦清單 | 可新增多個清單項目 |

### 清單項目欄位

| 欄位 | 說明 |
| --- | --- |
| 項目標題 | 項目的名稱；空白項目在儲存時會被忽略 |
| 已完成 | 勾選後標記該項目完成 |
| 開始 | 日期、時間、全天 |
| 結束 | 日期、時間、全天 |

### 日期與時間操作

- 點選日期欄位可選擇日期。
- 點選時間欄位可選擇時間。
- 開啟「整天」後，該項目的時間會以整日處理。
- 日期選擇器提供「今天」、「明天」、「下週」快速選項。
- 項目可只設定開始時間、只設定結束時間，或兩者都不設定。
- 若同時設定開始與結束，結束時間不可早於開始時間。

### 全天項目的提醒

全天項目會在當天 09:00 觸發提醒。若希望在不同時間提醒，請關閉「整天」並設定明確時間。

### 待辦與項目的完成邏輯

- 有清單項目時，待辦是否完成由「所有項目是否完成」決定。
- 勾選待辦本身會將所有清單項目一併標記完成。
- 取消勾選待辦會將所有清單項目一併標記未完成。
- 沒有清單項目時，使用「標記待辦完成」開關控制。

### 排序清單項目

- 在編輯畫面長按項目左側的拖曳把手，可上下拖曳調整順序。
- 使用 TalkBack 時，可透過項目上的「上移／下移」自訂動作調整順序。
- 刪除項目後，畫面底部會出現 Snackbar，可點選「復原」救回剛刪除的項目。

## 5. 待辦清單操作

### 分類

清單會自動分成以下區段，沒有內容的區段不顯示：

| 區段 | 判斷方式 |
| --- | --- |
| 逾期 | 有未完成項目已超過結束時間，或開始日期早於今天 |
| 今天 | 最早開始時間落在今天 |
| 接下來 | 最早開始時間在明天以後 |
| 無日期 | 沒有任何清單項目設定開始時間 |
| 已完成 | 待辦已完成 |

「已完成」區段可點標題收合或展開。

### 完成與封存

- 點選待辦左側核取方塊，切換完成狀態。
- 點選卡片右側箭頭可展開清單項目，直接勾選項目。
- 向右滑動卡片：切換完成狀態。
- 向左滑動卡片：封存待辦。
- 封存後可從 Snackbar 點選「復原」立即還原。

### 排序

點選標題列的排序按鈕，可選擇：

| 排序方式 | 說明 |
| --- | --- |
| 最早開始時間 | 依最早未完成項目的開始時間排序；無時間者排後 |
| 建立時間 | 新建立的待辦排在前面 |
| 手動排序 | 依使用者自訂順序；可長按拖曳卡片調整 |

手動排序僅套用於「全部」區段；已完成區段仍依完成時間排序。

### 搜尋

1. 點選標題列的搜尋圖示。
2. 輸入待辦標題或清單項目標題的關鍵字。
3. 搜尋結果會即時過濾。
4. 按返回鍵或關閉搜尋可清除關鍵字。

### 封存已完成

點選標題列「更多」選單中的「封存已完成」，可一次封存所有已完成的待辦。操作後會顯示封存數量。

## 6. 封存頁

從標題列「更多」選單進入「封存待辦」：

- 顯示所有已封存的待辦，依封存時間由新到舊排列。
- 點選「還原」可將待辦移回主要清單。
- 點選「刪除」會先顯示確認對話框；永久刪除後無法復原。
- 標題列提供「封存已完成」，可將目前所有已完成待辦移入封存。

## 7. 桌面小工具

### 新增小工具

1. 長按 Android 桌面空白處。
2. 選擇「小工具」。
3. 找到「Mini 待辦事項」的「待辦小工具」。
4. 拖放到桌面。
5. 在設定畫面選擇要顯示的待辦，點選「確定」。

### 小工具內容

- 待辦顏色圓點與標題。
- 最多顯示 5 個清單項目，未完成項目優先。
- 已完成項目顯示刪除線。
- 完成進度，例如「已完成 2/5」。
- 項目超過 5 個時顯示「+N 項」。

### 小工具操作

- 點選待辦標題或小工具空白處：開啟該待辦的編輯畫面。
- 勾選清單項目：立即更新完成狀態。
- 長按小工具並選擇「重新配置」：更換顯示的待辦。
- 若顯示的待辦已刪除，小工具會提示「此待辦已不存在」。

小工具不是秒級即時更新；資料變更、主題變更、裝置重開或每日背景工作時會刷新。

## 8. 提醒與通知

### 啟用通知

1. 建立含時間的清單項目後，App 會在第一次需要時詢問通知權限。
2. 若當時未允許，可前往「設定」→「通知與提醒」→「通知權限」開啟系統設定。
3. Android 13 以上必須允許通知，否則無法顯示提醒。

### 啟用精確提醒

1. 前往「設定」→「通知與提醒」→「精確提醒」。
2. 允許 App 使用精確鬧鐘。
3. 若未允許，App 仍會嘗試提醒，但可能因系統省電策略延遲。

### 通知操作

提醒通知提供兩個動作：

- **完成**：將該清單項目標記完成，並取消通知。
- **延後 10 分鐘**：10 分鐘後再次提醒。

點選通知本體會開啟所屬待辦。

## 9. 設定

### 一般

- **預設排序**：最早開始時間、建立時間、手動排序。

### 外觀

- **外觀**：跟隨系統、淺色、深色。
- **主題色彩**：跟隨桌布、預設藍、森林綠、薰衣草紫、暖陽橘、玫瑰粉、湖水綠。
- 「跟隨桌布」需要 Android 12 以上；較舊版本會自動使用預設藍。

### 通知與提醒

- 顯示通知權限狀態，可點選前往系統設定。
- 顯示精確鬧鐘狀態，可點選前往系統設定。

### 備份與還原

- **匯出備份**：選擇儲存位置，將所有待辦（含封存）匯出為 JSON。
- **匯入備份**：選擇 JSON 檔案，確認後覆蓋目前所有待辦與封存資料。

### 關於

- 顯示版本名稱與版本代碼。
- 顯示隱私說明與授權資訊。

## 10. 備份與還原

### 匯出

1. 開啟「設定」。
2. 點選「匯出備份」。
3. 選擇檔案儲存位置並確認。
4. 成功後會顯示匯出的待辦數量。

### 匯入

1. 開啟「設定」。
2. 點選「匯入備份」。
3. 選擇先前匯出的 JSON 檔案。
4. 確認「匯入會覆蓋目前所有待辦與封存資料」。
5. 成功後會顯示匯入的待辦數量。

注意事項：

- 匯入採覆蓋策略，不會合併新舊資料。
- 備份檔上限為 5 MB。
- 備份檔格式版本必須相符，否則會匯入失敗。
- 建議在匯入前先匯出目前資料。

## 11. 常見問題

### Q：為什麼收不到提醒？

請依序確認：

1. 通知權限是否已允許。
2. 精確鬧鐘權限是否已允許。
3. 系統是否開啟省電模式或限制背景活動。
4. 該清單項目是否已完成或所屬待辦是否已封存；已完成或封存的項目不會提醒。
5. 提醒時間是否已過。

### Q：為什麼整天項目的提醒在早上 9 點？

整天項目沒有明確時間，App 統一在當天 09:00 提醒。若需要其他時間，請關閉「整天」並設定時間。

### Q：為什麼小工具沒有立即更新？

小工具由系統排程更新，並非每秒刷新。資料或主題變更後通常會很快更新；若未更新，可長按小工具選擇「重新配置」或等待每日背景工作。

### Q：手動排序為什麼只在「全部」區段有效？

手動排序的順序是相對於完整清單，因此分類區段仍會依時間條件顯示；只有「全部」區段會完全依照手動順序呈現。

### Q：跨時區後日期為什麼改變？

純日期資料以裝置目前時區轉換為時間戳儲存。跨時區移動時，日期可能因此位移。這是目前已知限制。

### Q：匯入備份會發生什麼事？

目前所有待辦與封存資料會先被刪除，再寫入備份內容。此操作無法復原，請先確認或先匯出目前資料。

### Q：App 會上傳我的資料嗎？

不會。App 沒有網路權限，也沒有帳號、廣告、分析或追蹤 SDK。所有資料只存在裝置本機。

### Q：如何完全清除資料？

解除安裝 App 會移除本機資料庫與設定。若只想清除待辦，可逐一刪除，或匯入一份空白備份（需自行建立符合格式的 JSON）。

## 12. 資料與隱私

- 待辦與封存資料儲存在 Room 資料庫。
- 設定儲存在 DataStore。
- Android 自動雲端備份已關閉。
- 跨裝置搬移請使用 JSON 匯出／匯入。
- 更多說明請見 [隱私說明](PRIVACY.md)。
