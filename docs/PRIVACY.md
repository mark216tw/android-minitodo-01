# 隱私說明

最後更新：2026-11-10

Mini 待辦事項（以下稱「本 App」）以離線運作為核心設計。本文件說明本 App 蒐集、使用與保存資料的方式。

## 1. 資料儲存位置

本 App 的所有待辦、清單項目、封存資料與設定，均儲存在使用者裝置本機：

- 待辦與清單項目：Room 資料庫（`minitodo.db`）。
- 設定：DataStore Preferences。
- 桌面小工具設定：Glance 狀態與 DataStore。

本 App 不會將上述資料上傳到任何伺服器。

## 2. 不蒐集的資料

本 App 不蒐集、不傳輸、也不分享以下資料：

- 姓名、電子郵件、電話號碼或其他帳號資訊。
- 位置資訊。
- 通訊錄、通話紀錄、簡訊。
- 照片、影音或檔案（使用者主動匯出備份時除外）。
- 裝置識別碼或用於廣告追蹤的識別碼。
- 使用行為分析或崩潰分析資料。

本 App 不包含廣告、分析、追蹤或社群 SDK。

## 3. 網路連線

本 App 未宣告 `INTERNET` 權限，因此不具備網路存取能力。所有功能皆在本機完成。

## 4. 權限說明

| 權限 | 用途 | 是否必要 |
| --- | --- | --- |
| `POST_NOTIFICATIONS` | 顯示待辦時間提醒通知 | 需要提醒時必要 |
| `SCHEDULE_EXACT_ALARM` | 在指定時間準確觸發提醒 | 選用；未授權時改用非精確排程 |
| `RECEIVE_BOOT_COMPLETED` | 裝置重新開機後重新排程提醒 | 提醒功能必要 |
| `VIBRATE` | 通知震動 | 選用 |

本 App 不要求儲存權限。備份匯出與匯入透過 Android 系統檔案選擇器（Storage Access Framework）完成，使用者可自行決定檔案位置。

## 5. 通知

提醒通知僅在使用者設定的時間觸發，內容包含：

- 清單項目標題。
- 事件類型（開始或結束）。
- 所屬待辦標題。

通知不會包含廣告或行銷內容。

## 6. 備份

- 備份由使用者主動觸發。
- 匯出的 JSON 檔案包含所有待辦、清單項目、封存資料與相關時間資訊。
- 備份檔案未加密，請妥善保管，避免放置於公開位置。
- 匯入備份會覆蓋目前所有資料；操作前會顯示確認對話框。

## 7. Android 自動備份

本 App 已關閉 Android 自動雲端備份與裝置移轉備份（`allowBackup=false` 與 backup rules 全數排除）。若需要跨裝置搬移資料，請使用 App 內的 JSON 匯出／匯入功能。

## 8. 桌面小工具

桌面小工具僅讀取使用者選擇的待辦資料，並在本機顯示。小工具不會將資料傳送到裝置外。

## 9. 第三方元件

本 App 使用 AndroidX、Jetpack Compose、Room、DataStore、WorkManager 與 Jetpack Glance 等開放原始碼元件。這些元件依其原授權提供，主要為 Apache License 2.0。本 App 未整合第三方廣告或分析服務。

## 10. 兒童隱私

本 App 不蒐集任何個人資料，也未針對兒童設計專屬功能或行銷內容。任何年齡層使用者皆可安心使用。

## 11. 資料刪除

- 解除安裝本 App 會移除裝置上的資料庫與設定。
- 使用者可在 App 內刪除個別待辦或項目。
- 匯入空白備份可清除所有待辦資料（需自行建立符合格式的 JSON）。

## 12. 政策變更

若未來版本調整資料處理方式，將於本文件與版本說明中更新，並隨版本發行公告。

## 13. 聯絡方式

若對隱私有任何疑問，請透過 GitHub 儲存庫的 Issue 提出：

<https://github.com/mark216tw/android-minitodo-01/issues>

請勿在公開 Issue 中附上含個人資料的備份檔或敏感資訊。
